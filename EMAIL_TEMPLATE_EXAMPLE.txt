CUSTOMIZATION OPTIONS
================================================================================

You can customize the email template by editing hertz_email_generator.py:

1. SUBJECT LINE
   Edit the create_email_subject() method (lines 159-163)
   
   Current format:
   "HERTZ LOGISTICS CONFIRMATION - VIN # ({vin}) - CONDITION/LOCATION - 
    RESPONSE NEEDED BY {deadline}"

2. EMAIL BODY
   Edit the create_email_body() method (lines 165-184)
   
   You can:
   - Change the greeting
   - Modify the questions
   - Add additional information
   - Change the signature

3. RESPONSE DEADLINE
   Edit the generate_response_deadline() method (line 155)
   
   Default: 24 hours from now
   Change hours_from_now=24 to your preferred deadline

4. RECIPIENTS
   Currently includes only Hertz representative emails
   Purchaser emails are excluded automatically
   
   To change this logic, edit lines 192-194:
   if self.data.get('hertz_rep_emails'):
       mail.To = "; ".join(self.data['hertz_rep_emails'])
