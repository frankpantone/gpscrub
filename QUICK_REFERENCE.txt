├────────────────────────────────────────────────────────────────────────────┤

│  ✅ Extracts vehicle data from gate release PDFs                          │
│  ✅ EXCLUDES purchaser emails (first email in PDF)                        │
│  ✅ INCLUDES Hertz rep emails as recipients                               │
│  ✅ Sets deadline to 1100 (11:00 AM) on NEXT DAY                          │
│  ✅ ATTACHES the PDF to email draft                                       │
│  ✅ Creates Outlook draft for your review                                 │
│                                                                            │

┌────────────────────────────────────────────────────────────────────────────┐
│ 🚀 HOW TO USE                                                              │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│  METHOD 1: Double-click                                                    │
│    → Double-click: process_pdf.bat                                         │
│                                                                            │
│  METHOD 2: Single PDF                                                      │
│    → python hertz_email_generator.py yourfile.pdf --auto                   │
│                                                                            │
│  METHOD 3: All PDFs in folder                                              │
│    → python batch_process_pdfs.py --auto                                   │

┌────────────────────────────────────────────────────────────────────────────┐
│ 📧 EMAIL FILTERING (NEW!)                                                  │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│  EXCLUDED (Not included as recipients):                                    │
│    • First @hertz.com email in document = Purchaser email                 │
│    • Example: konovak@hertz.com [EXCLUDED]                                │
│                                                                            │
│  INCLUDED (Added to TO: field):                                            │
│    • All subsequent @hertz.com emails = Hertz reps                        │
│    • Example: Khadijah.Goudeau@hertz.com, BSwift@hertz.com               │
│                                                                            │
│  WHY: Prevents accidental emails to purchasers                            │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────┐
│ ⏰ DEADLINE FORMAT (NEW!)                                                  │

│                                                                            │
│  Subject Line Format:                                                      │
│    HERTZ LOGISTICS CONFIRMATION - VIN # (xxx) -                           │
│    CONDITION/LOCATION - RESPONSE NEEDED BY 1100 on 10/29                  │
│                                                                            │
│  Always: 1100 (11:00 AM) on the NEXT DAY                                  │
│    • Today is 10/28 → Shows "1100 on 10/29"                               │
│    • Today is 10/29 → Shows "1100 on 10/30"                               │
