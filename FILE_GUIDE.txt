                     FILE DESCRIPTIONS
================================================================================

🚀 EXECUTABLES/SCRIPTS
----------------------

process_pdf.bat
  └─> Windows batch file launcher
      • Double-click to run
      • Automatically detects PDFs
      • Checks for Python and dependencies
      • Offers menu for single/batch processing
      • Best for non-technical users

hertz_email_generator.py
  └─> Main Python script
      • Processes single PDF files
      • Extracts vehicle info, emails, location
      • Creates Outlook email drafts
      • Can run interactively or automatically
      • Command: python hertz_email_generator.py [file.pdf] [--auto]

batch_process_pdfs.py
  └─> Batch processing script
      • Processes multiple PDFs at once
      • Creates summary reports
      • Generates individual email drafts
      • Saves detailed batch report
      • Command: python batch_process_pdfs.py [--auto]

================================================================================
                     TYPICAL WORKFLOW
================================================================================

FOR FIRST-TIME USERS:
1. Read QUICK_START.md
2. Double-click process_pdf.bat
3. Review email draft in Outlook
4. Send when ready!

FOR SINGLE PDF:
1. Place PDF in folder
2. Run: python hertz_email_generator.py --auto
3. Review draft in Outlook
4. Send

FOR MULTIPLE PDFs:
1. Place all PDFs in folder
2. Run: python batch_process_pdfs.py --auto
3. Review each draft in Outlook
4. Check batch_report_*.txt for summary
5. Send drafts when ready

FOR DEVELOPERS:
1. Read README.md
2. Review pdf_structure_analysis.md
3. Check source code in hertz_email_generator.py
4. Customize as needed
