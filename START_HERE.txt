                           📋 WHAT THIS DOES
╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌

Automatically processes Hertz gate release PDFs and creates email drafts:

  ✓ Extracts VIN, year, make, model
  ✓ Finds pickup location and address
  ✓ Identifies Hertz representative emails
  ✓ Creates Outlook email draft with your template
  ✓ Pre-fills subject, recipients, and body
  ✓ Opens draft for you to review and send

                         🛠️  TROUBLESHOOTING
╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌

  ❌ "Python not found"
      → Install Python from python.org
      → Make sure to check "Add to PATH"

  ❌ "No module named pypdf"
      → Run: pip install pypdf pywin32

  ❌ "Error creating Outlook draft"
      → Make sure Outlook is installed
      → Open Outlook once to configure it

  ❌ "Wrong data extracted"
      → Check: pdf_extracted_text.txt
      → Verify PDF is a standard gate release form

  ❌ Still stuck?
      → Read QUICK_START.md for step-by-step help
